# AI Explain My Data

AI Explain My Data is a web-based platform that helps users understand
their datasets without requiring advanced knowledge of statistics or
data science.

Users can upload a CSV dataset and receive automatic data analysis,
statistics, visualizations and AI-powered explanations.

## Features

- CSV dataset upload
- Automatic dataset profiling
- Row and column analysis
- Missing value detection
- Duplicate row detection
- Numeric and categorical column detection
- Statistical analysis
- Dataset preview
- Automatic charts
- AI-powered data explanations
- Secure server-side AI integration

## Technology Stack

### Frontend

- HTML5
- CSS3
- JavaScript
- Chart.js

### Backend

- Node.js
- Express.js
- Multer
- CSV Parser

### AI

- Generative AI API
